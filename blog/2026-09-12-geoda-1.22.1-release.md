We are excited to announce that **GeoDa 1.22.1** (released August 26, 2026) is now available for download! This release introduces a new versioning scheme, a Linux AppImage build, ARM64 support for Windows, updated dependencies, and a number of bug fixes.

## New Versioning Scheme

GeoDa now uses a standard `major.minor.patch` version (1.22.1, instead of the previous `1.22.0.21` format). Version numbers in this scheme can be compared reliably by standard software tooling, so automated update checks — for example in computer lab and classroom installations that deploy GeoDa on many machines — can detect and install new releases automatically.

## AppImage for Linux

GeoDa for Linux is now distributed as an [AppImage](https://appimage.org/) that bundles all of its dependencies. A single file runs on most modern 64-bit Linux distributions, including Ubuntu, Debian, Fedora, openSUSE, and Arch Linux, so you no longer need separate packages per distribution.

## Windows on ARM64

GeoDa now ships a native ARM64 installer for Windows on ARM devices (such as recent Snapdragon-based laptops), alongside the existing x86 and x64 installers.

## Updated Dependencies

GeoDa 1.22.1 is built against updated core libraries, including a newer version of GDAL, and the Windows build has been modernized with updated dependency tooling.

## Bug Fixes

- Fixed vcredist detection on the 32-bit Windows installer by using a static registry key.
- Fixed an undeclared `MIN` compile error by using `std::min` with the `<algorithm>` header.
- Fixed a const-correctness error with newer GDAL by cloning `OGRSpatialReference`.
- The macOS bundle version in `Info.plist` is now updated automatically during the build so it always matches the release.
